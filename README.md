# QR Code Component

Projeto desenvolvido como desafio do [Frontend Mentor](https://www.frontendmentor.io/), com o objetivo de praticar HTML e CSS.

## 📌 Sobre o projeto

Este projeto consiste em um componente de QR Code com:

* QR Code para acesso ao Frontend Mentor
* Título e descrição
* Layout responsivo
* Fonte Outfit
* Estilização utilizando CSS

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 🎯 O que pratiquei

Durante o desenvolvimento, pratiquei:

* Estruturação semântica com HTML
* Flexbox
* Variáveis CSS
* Responsividade
* Tipografia
* Espaçamentos com `padding` e `margin`
* Uso de fontes externas
* Organização de um projeto simples
* Git e GitHub

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela, mantendo o componente centralizado e ajustando sua largura conforme o espaço disponível.
